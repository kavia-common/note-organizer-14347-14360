# Release Automation

Native (Android) CI step (required):
- Do NOT call `./gradlew` at the repo root directly.
- Use ONE of the provided commands that ensures native project generation:

Recommended:
  sh ./gradle-preflight.sh :app:assembleDebug

Alternatives:
  sh ./run-gradle-direct.sh :app:assembleDebug
  sh notes_frontend/android/run-gradle-here.sh :app:assembleDebug
  npm run ensure:gradlew && ./gradlew :app:assembleDebug

Why:
- This is an Expo app. The native Gradle wrapper lives at notes_frontend/android/gradlew
  and is generated by Expo Prebuild on demand. The preflight commands do both steps safely.

Web:
  sh ./build-web.sh

Version bump:
- Update version in notes_frontend/app.json
- Update CHANGELOG.md and RELEASE-NOTES.md
- Tag the repository
