# Known Issues

1) CI: ./gradlew not found
- Cause: This is an Expo project; the native Android gradle wrapper is generated by Expo Prebuild.
- Fix: Use a provided ensure/preflight step BEFORE invoking gradle:
  - sh ./gradle-preflight.sh :app:assembleDebug
  - OR sh ./run-gradle-direct.sh :app:assembleDebug
  - OR sh ./ci-ensure-and-run-gradle.sh :app:assembleDebug
  - OR npm run ensure:gradlew && ./gradlew :app:assembleDebug
  - If CI is hardcoded to run exactly ./gradlew, insert a pre-step:
    sh ./ensure-root-gradlew.sh

2) Web build assets paths
- Use build-web.sh to export a web build. Assets are emitted into notes_frontend/dist-web.

3) AsyncStorage data loss when clearing app data
- Clearing app data removes notes/folders. Use Export (exportNotesToClipboard) to save JSON before clearing.

4) Large note content performance on low-end devices
- Consider debouncing and virtualized lists; current list is FlatList with moderate performance defaults.

5) Motion sensitivity
- Reduced-motion (per-user setting) can be respected by minimizing animations; the current app uses subtle animations only in Toast.
