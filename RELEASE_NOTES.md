Ocean Professional Notes – Release Notes (v1.0.0)

New:
- Complete notes app (create, edit, view, delete)
- Organize with folders (create, rename, delete)
- Pin notes; pinned items are visually highlighted
- Search and sort (Recent, Created, Title)
- Note color tagging (picker in editor; accent bar on cards)
- Empty state with CTA; onboarding tip on first run
- Inline rename (long-press a note in list)
- Delete confirmation dialog
- Snackbar confirmation after save and on copy
- Help and About screens
- Accessibility labels and test IDs across key controls
- Local persistence via AsyncStorage
- Preferences persistence (selected folder, sort mode)

UI Theme:
- Ocean Professional (blue #2563EB, amber #F59E0B, clean surfaces, soft shadows, rounded corners)

Dev Notes:
- Expo-managed app; Android wrapper is generated by prebuild.
- Use scripts:
  - bash ./build-android.sh (recommended)
  - make build-android
  - bash ./ci-run-gradle.sh :app:assembleDebug

Known:
- CI pipelines that call ./gradlew at repo root must run prebuild first or use the provided scripts.
