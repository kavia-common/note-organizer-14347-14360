# Telemetry & Analytics (Future)

Current
- No telemetry or analytics; fully offline/local app.

Guidelines (if adding later)
- Opt-in only; provide a clear toggle in Settings.
- Collect minimal, anonymized event data (e.g., feature usage) with no content.
- Respect user privacy and local-region data storage regulations.
- Use a lightweight client and batch events with network/backoff handling.
