# Architecture Overview — Ocean Professional Notes App

This document describes the frontend architecture for the Expo React Native app.

## Goals

- Simple, maintainable codebase with strong typing
- Ocean Professional visual style
- Offline-first with local persistence (AsyncStorage)
- Clear mental model: Notes + Folders with filters, search, pinning

## Modules

- Theme: `src/theme/colors.ts`
  - Defines tokenized Colors, Radii, Spacing, Elevation
- Types: `src/types.ts`, `src/store/types.ts`
  - Data models for Note/Folder and store shapes
- Storage: `src/services/storage.ts`
  - AsyncStorage with JSON helpers
- Store: `src/store/NotesContext.tsx`
  - Loads/saves notes and folders, exposes CRUD
  - Controls selection (folder) and sort mode
- Components:
  - AppBar, FAB, FolderPill, NoteCard, EmptyState, Snackbar
- Screens:
  - NotesListScreen: Search bar + folder pills + NoteCard list
  - NoteEditorScreen: Title, folder chips, text area
  - NoteViewerScreen: Read-only note display with pin/edit
  - FolderManagerScreen: Add/rename/delete folders
  - Help/About: Informational
- Navigation:
  - Route union defined in `src/navigation/types.ts`
  - Local router in `App.tsx` switches on Route

## Data Flow

- App boot:
  - NotesProvider loads notes and folders from AsyncStorage
  - State is provided via context
- User actions:
  - CRUD functions update context (immutable updates)
  - Side effect persists to AsyncStorage
- Filters and search:
  - Folder filter from context
  - Search query debounced via `useDebouncedValue`
  - Sort configurable via SearchBar control

## Build & CI

- Expo SDK 53 / RN 0.79
- Android native wrapper generated by `expo prebuild`
- Provided scripts:
  - App-level: `notes_frontend/scripts/bootstrap-android.sh`, `ci-build-android.sh`
  - Root-level: `prepare-android-wrapper.sh`, `build-android.sh`, `gradle-check.sh`, `gradlew` shim
- CI should run bootstrap before any direct `./gradlew` invocation.

## Security & Privacy

- No remote services; all data stays on device
- No secrets or env vars required for app function
