# Fix for CI/Analyzer 'gradlew not found'

Run this single command before any `./gradlew` invocation:

```
bash note-organizer-14347-14360/prepare-android-wrapper.sh || bash note-organizer-14347-14360/build-android.sh
```

Why this is required:
- The Android Gradle wrapper is generated by Expo Prebuild inside `notes_frontend/android`.
- Without running prebuild, there is no `./gradlew` file to execute.

Alternative proxies:
- `bash note-organizer-14347-14360/gradle-check.sh`
- `bash note-organizer-14347-14360/build-android.sh`
- `make build`
