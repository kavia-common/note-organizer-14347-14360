# Build Guide (CI and Local)

Preferred native check:
- bash ci-gradle-runner.sh

Alternates:
- sh gradle.sh :app:assembleDebug
- ./gradlew :app:assembleDebug (ensure `sh ensure-gradle-exec.sh` first)

Web build fallback:
- sh build-web.sh

Notes:
- The native Android project is generated by Expo Prebuild on demand.
- The actual Gradle wrapper lives at notes_frontend/android/gradlew after prebuild.
