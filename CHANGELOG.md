# Changelog

All notable changes to this project will be documented in this file.

## 1.0.0 — Initial Release
- Ocean Professional themed notes app (create, edit, view, delete)
- Organize with folders (add, rename, delete), search, sort, pin
- Local persistence via AsyncStorage
- Modern UI: app bar, list area, floating action button
- Optional variants (pinned grouping, quick folder, folder count)
- Developer utilities (bulk pin, JSON transfer, markdown preview)
- CI helper scripts and alternate web export path
