# App Usage Guide

Create
- Tap the + button or the Add action in the top app bar to create a new note.
- Enter a title, choose a folder (optional), and start writing.
- Tap Save to store your note locally.

Edit
- Tap any note in the list to view it, then choose Edit to modify.
- Changes are saved when you tap Save.

Organize
- Use Manage in the folder row to add/rename/delete folders.
- Select a folder pill to filter notes by that folder.
- Use the Sort button to switch between Recent, Created, or Title sorting.

Search
- Type in the search bar to filter notes instantly by title/content.

Pin
- Tap Pin on a note to keep it at the top of the list; tap again to unpin.

Delete
- Tap Delete on a card and confirm to remove a note.

Export/Import (optional)
- Export to clipboard: see EXPORT-README.md
- Import from JSON: see IMPORT-README.md

Tips
- Minimalist UI, rounded corners, subtle gradients, smooth transitions.
- Blue accents for primary actions; amber for highlights.
