# Android Build (Notes App)

This app uses Expo SDK 53. The native Android Gradle wrapper is generated by Expo Prebuild.

Steps:
1) Bootstrap native wrapper:
```
bash ./scripts/bootstrap-android.sh
```

2) Build with Gradle:
```
bash ./scripts/ci-build-android.sh
```

Equivalent npm scripts:
- `npm run ci:bootstrap-android`
- `npm run ci:build-android`

If a CI tool tries to run `./gradlew` at the repository root, use the root shim and helper scripts documented in:
- `../../README-GRADLE-EXEC.md`
- `../../BUILDING.md`
