# Security & Privacy

Data scope
- Notes and folders are stored locally on the device using AsyncStorage.
- No remote sync or account sign-in is included by default.

Privacy
- Your notes never leave the device unless you explicitly export/share them.
- When exporting or sharing, review the content and destination carefully.

Security
- Treat exported JSON carefully; it may contain sensitive information.
- If integrating a backend in the future, add authentication and encryption in transit.
