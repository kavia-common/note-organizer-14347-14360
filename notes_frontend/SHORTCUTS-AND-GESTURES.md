# Shortcuts & Gestures (Ocean Notes)

Mobile gestures:
- Tap a note: open viewer
- Long-press actions (OS-level selection) are not required in this app; use inline buttons (Pin/Delete)
- Pull to refresh is not needed (local data only)

Tips:
- Use the + floating action button to create a note
- Use the folder pills to filter
- Manage folders from the list via "+ Manage"
