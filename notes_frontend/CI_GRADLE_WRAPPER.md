Some CI environments expect the Gradle wrapper at the working directory root.
For this Expo project, the wrapper is generated by Expo prebuild here:
- android/gradlew

If your CI tool attempts to run ./gradlew from the root, set the working directory to:
- note-organizer-14347-14360/notes_frontend

Or invoke the wrapper with the explicit path:
- ./android/gradlew :app:assembleDebug
