# Icons & Splash

Assets (configured in app.json):
- Icon: notes_frontend/assets/icon.png
- Splash: notes_frontend/assets/splash-icon.png
- Adaptive (Android): notes_frontend/assets/adaptive-icon.png
- Favicon (Web): notes_frontend/assets/favicon.png

Guidelines (Ocean Professional):
- Primary: Blue #2563EB with white negative space
- Secondary accent: Amber #F59E0B (sparingly)
- Shape: Rounded corners or circular motif
- Background: Subtle gradients or flat

Export guidance:
- Provide 1024x1024 base icon with transparent background
- Keep splash minimal, centered icon on white/very light background

Updating assets:
- Replace PNG files in notes_frontend/assets/
- No code changes needed unless you adjust app.json paths
