# Components — Ocean Professional

Conventions:
- Rounded corners (Radii.lg or Radii.xl)
- Subtle shadows via Elevation tokens
- Keep actions high-contrast with primary/secondary accents
- Use accessibilityRole and accessibilityLabel for interactive elements

Components:
- AppBar: Top bar with title and optional actions
- FAB: Floating add button
- NoteCard: Note preview with pin/delete actions
- FolderPill: Filter chips for folders
- EmptyState: Friendly placeholder prompt
- ConfirmModal: Confirm destructive actions
- Snackbar: Short feedback messages
- SearchBar: Query input and sort toggle
