# Theme Usage

Import tokens:
- Colors, Radii, Spacing, Elevation from `src/theme/colors`

Guidelines:
- Surfaces: Colors.surface with border #E5E7EB and subtle Elevation.sm
- Actions: primary (blue) for primary, secondary (amber) for highlight
- Text: Colors.text for primary content, Colors.textMuted for captions
- Corners: Radii.lg for cards, Radii.xl for pills, Radii.round for FAB
