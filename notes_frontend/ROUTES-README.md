# Routes

The app uses a lightweight in-file Router (App.tsx) with these routes:
- home: notes list
- create: note editor (new)
- edit: note editor (existing)
- view: note viewer
- folders: folder manager

Future enhancements:
- Integrate a full navigation library (e.g., React Navigation) if deep linking is required.
- Map SettingsHelpScreen and AboutScreen to actions in the AppBar when needed.
