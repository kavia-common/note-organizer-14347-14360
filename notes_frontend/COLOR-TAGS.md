# Color Tags

Notes include an optional `color` field which can be used to display a small accent or label.

Utilities:
- `tagToHex(tag)` in `src/utils/colorTags.ts` maps tags to hex colors aligned with the Ocean Professional palette.

Suggested tags:
- blue, amber, red, green, purple (or null for default)

Future UI idea:
- Show a small vertical accent bar on NoteCard using the mapped color for quick visual categorization.
