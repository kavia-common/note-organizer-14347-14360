# Folders — Overview

- Create, rename, and delete folders in Folder Manager.
- Assign a note to a folder in the editor via chips row.
- Filter notes list by folder using the pills at the top.
- Deleting a folder does not delete notes; it unassigns them (folderId -> null).

Optional quick actions:
- Inline new folder creation using `NewFolderQuickAction` near the folder pills row.
