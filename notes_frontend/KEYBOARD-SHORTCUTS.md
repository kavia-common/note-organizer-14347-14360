# Keyboard Shortcuts (Hints)

Mobile:
- System keyboard provides text editing shortcuts.
- Consider using hardware keyboard for emulator/simulator.

Web (Expo web dev):
- Cmd/Ctrl + R: Reload
- Cmd/Ctrl + S: Save in editor triggers fast refresh
- Search field: Focus manually (tap/click)

App ideas (not implemented by default):
- Cmd/Ctrl + N: New note
- Cmd/Ctrl + F: Focus search
- Esc: Blur inputs / go back
