## Theming and Design

Ocean Professional style:
- Colors: primary #2563EB (blue), secondary #F59E0B (amber), error #EF4444
- Background #f9fafb, Surface #ffffff, Text #111827
- Rounded corners, subtle shadows, minimalist layouts
- Components use tokens from `src/theme/colors.ts` (Colors, Radii, Spacing, Elevation)

## State Management

`src/store/NotesContext.tsx`
- Provides CRUD for Notes and Folders
- Persists to AsyncStorage via `src/services/storage.ts`
- Sort modes: updated, created, title
- Folder selection filter and pinning flows

Types:
- `src/types.ts` (Note, Folder)
- `src/store/types.ts` (SortMode, NotesContextShape)

## Screens and Navigation

Navigation is an in-app union of route types:
- `Route` defined in `src/navigation/types.ts`
- Screens:
  - NotesListScreen: Search, sort, folder filter, list with NoteCard
  - NoteEditorScreen: Create/edit with folder chips
  - NoteViewerScreen: Read-only view with quick actions
  - FolderManagerScreen: Manage folders
  - HelpScreen, AboutScreen: Lightweight info screens

`App.tsx` uses `NotesProvider` and a local stateful router.

## Development

- Install deps: `npm install` (inside notes_frontend)
- Start: `npm start` (Expo)
- Lint: `npm run lint`
- Web preview: `npm run web` (basic)

## Android Build (CI/Native)

Gradle wrapper is generated by Expo Prebuild:
- Bootstrap: `npm run ci:bootstrap-android` or `bash ./scripts/bootstrap-android.sh`
- Build: `npm run ci:build-android` or `bash ./scripts/ci-build-android.sh`

From repo root:
- `bash note-organizer-14347-14360/prepare-android-wrapper.sh`
- `bash note-organizer-14347-14360/build-android.sh`
- Proxy gradle tasks: `bash note-organizer-14347-14360/gradle-check.sh`

## Troubleshooting

- gradlew not found: Run the bootstrap scripts above to generate `notes_frontend/android/gradlew`.
- AsyncStorage package: Installed via `@react-native-async-storage/async-storage`; Expo SDK 53 compatible.
- Clipboard: `expo-clipboard` used for copy actions.
- Types: Ensure TS version aligns with Expo SDK 53 (configured in package.json).

## Accessibility & UX

- Buttons and primary actions include accessibility roles/labels where applicable.
- Debounced search for performance (`useDebouncedValue`).
- Snackbar component provides copy confirmations.
