# CI Configuration Hint

If your CI tool insists on calling `./gradlew` at the repository root and cannot run the prebuild step first, set it to call one of these instead:

Preferred:
- `bash note-organizer-14347-14360/build-android.sh` (bootstraps and builds)
- `bash note-organizer-14347-14360/gradle-check.sh` (bootstraps and runs `gradle check` or given tasks)

Alternative:
- `bash note-organizer-14347-14360/run-gradle.sh` (bootstraps then proxies to generated wrapper)
- `bash note-organizer-14347-14360/preflight-ci.sh` (pre-step)

If the CI allows aliasing the Gradle command, map:
- `./gradlew` -> `bash note-organizer-14347-14360/gradlew.auto`

This ensures the Android wrapper is generated by Expo Prebuild prior to any Gradle invocation.
