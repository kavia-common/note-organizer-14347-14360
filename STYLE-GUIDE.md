# Ocean Professional — Style Guide

Principles
- Modern, minimalist, calm
- Blue primary (#2563EB), amber accent (#F59E0B)
- Subtle gradients, soft shadows, rounded corners
- Clear hierarchy, generous spacing

Components
- App Bar: strong title, optional right actions; Add (+) as primary
- Cards: rounded corners, 1px border (#E5E7EB), light shadow
- Buttons: blue primary for primary actions; amber sparingly for highlight
- Pills/Chips: light gray background with blue active state

Typography
- Titles: 18–20, bold 700–800
- Body: 14–16, color #111827
- Muted: #6B7280 for secondary text

Motion
- Subtle: fade/slide, < 220ms
- Avoid heavy or distracting animations

Accessibility
- Maintain AA contrast
- Minimum touch target 44x44 dp
- Ensure informative accessibility labels

Examples
- NoteCard: title (bold), 2-line preview (muted), meta timestamp
- Editor: large title input, spacious content area, folder chips
