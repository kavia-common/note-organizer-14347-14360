# FAQ

Why is ./gradlew missing?
- This is an Expo project; the native wrapper is generated by Expo Prebuild inside notes_frontend/android.
- See CI-TROUBLESHOOTING.md and GRADLE-ENTRYPOINTS.md for correct commands.

Where is the app entry point?
- notes_frontend/App.tsx

How does data persist?
- AsyncStorage via services/storage.ts. No backend by default.

Can I add a new screen?
- Place it under src/screens and wire via the Router in App.tsx. Use Ocean tokens for styling.

How do I export/import data?
- See EXPORT-README.md and IMPORT-README.md. Utilities live under src/utils.
