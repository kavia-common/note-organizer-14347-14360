If your analyzer or CI is attempting to run `./gradlew` directly at the repository root, it will fail until the native Android wrapper is generated by Expo Prebuild.

Run one of:
- bash note-organizer-14347-14360/prepare-android-wrapper.sh
- bash note-organizer-14347-14360/build-android.sh
- bash note-organizer-14347-14360/gradle-check.sh

These scripts bootstrap the wrapper under notes_frontend/android and delegate Gradle tasks accordingly.
