CI build hint (Android):

Use this command from the repository root to build the Android app:
- bash ./gradlew.shim :app:assembleDebug

The script will:
1) Ensure the Expo Android wrapper exists (runs prebuild if needed)
2) Forward to notes_frontend/android/gradlew with all provided arguments

Alternative targets:
- make build-android
- bash ./ci-run-gradle.sh :app:assembleDebug
