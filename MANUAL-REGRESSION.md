# Manual Regression Checklist

Basic
- [ ] App launches without errors
- [ ] List shows existing notes or EmptyState
- [ ] FAB opens the editor

Create/Edit/View/Delete
- [ ] Create new note, save
- [ ] Edit existing note, save
- [ ] View displays updated timestamp and content
- [ ] Delete prompt appears and removes note when confirmed

Folders
- [ ] Add folder, rename, delete
- [ ] Assign note to folder from editor
- [ ] Filter by folder pills

Search/Sort
- [ ] Typing in search filters by title/content
- [ ] Sort cycles between Recent/Created/Title

Pin
- [ ] Pin toggles status and ordering

Persistence
- [ ] Exit and relaunch app retains state

Accessibility/UX
- [ ] Buttons are labeled and accessible
- [ ] Layout handles large font sizes gracefully
