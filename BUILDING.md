# Building the Android app (CI and local)

This repository uses Expo SDK 53 with React Native 0.79. The native Android Gradle wrapper is generated by Expo Prebuild.

If your CI or analyzer expects `./gradlew` at repository root, use the helper scripts below to first generate the wrapper and then run Gradle.

Recommended steps:
1) Prepare/generate the native wrapper
```
bash note-organizer-14347-14360/prepare-android-wrapper.sh
```

2) Build the Android app
```
bash note-organizer-14347-14360/build-android.sh
```

What these scripts do:
- Install dependencies if needed (inside `notes_frontend`)
- Run `npx expo prebuild --platform android` to generate `notes_frontend/android/gradlew`
- Invoke `./gradlew assembleDebug` inside the generated `android` folder

For local development:
- `cd note-organizer-14347-14360/notes_frontend`
- `npm install`
- `npm start` (or `npm run android` if you have Android tooling)
