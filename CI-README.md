# CI Build Guidance

Preferred:
- bash ci-gradle-runner.sh

Alternate:
- chmod +x ./gradlew && ./gradlew :app:assembleDebug

Notes:
- The Android project is generated by Expo Prebuild. The root-level `gradlew` shim will generate it if missing and then delegate to `notes_frontend/android/gradlew`.
- Ensure Node/npm is available in the CI image and outbound network is allowed for Gradle/Expo downloads.
