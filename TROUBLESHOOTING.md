# Troubleshooting

"./gradlew: No such file or directory"
- Reason: The Android project/gradle wrapper is generated by Expo prebuild under notes_frontend/android.
- Fix options:
  1) Run: bash note-organizer-14347-14360/ci-gradle-check.sh
  2) Ensure exec perms then call wrapper:
     - bash note-organizer-14347-14360/set-exec-gradle.sh
     - ./gradlew check
  3) Use the fallback runner:
     - bash note-organizer-14347-14360/tools/gradle-check.sh

"curl/unzip missing" when Gradle tries to fetch wrapper
- Ensure your CI image provides curl and unzip or pre-populate gradle/wrapper/gradle-wrapper.jar

Expo prebuild fails
- Verify Node and npm versions are supported by Expo SDK 53
- Re-run: cd notes_frontend && npx expo prebuild --platform android
- Check network access and Android SDK availability if building locally
